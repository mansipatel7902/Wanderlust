# Wanderlust 🌍

Wanderlust is a travel listing web application where users can explore
different stays and manage travel listings.

## ✨ Features

- View all listings
- View individual listing details
- Create a new listing
- Edit existing listings
- Delete listings
- Listing cards with images
- Responsive navigation bar
- Footer
- Hover effects on listing cards

## 🛠️ Tech Stack

- HTML
- CSS
- Bootstrap
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
